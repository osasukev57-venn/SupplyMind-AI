# v0.9.1-rc.12

同步后续云端分析修复、人工／导入历史回填闭环，以及基于实际录像的 README 截图与视频入口。

## 主要变化

- 人工与导入记录发布后自动重新核对相关回填任务。
- 根据任务创建时的配置、业务日历及请求范围区分等待、部分完成、完成，不再用同月任意一条数据代表整段范围补齐。
- 运行／重试核对已有发布数据，重复运行不重复发布；任务进度持久化。
- 发布后进度更新失败单独提示，避免将已发布记录误报为拒绝。
- 同步 Agent 标准事实、分段采用检查、生成时报告读取等后续修复。
- 新增完整演示视频、普通话 AI 男声、字幕与实录截图。不公开个人模型 Key 或录制后的业务数据快照。

## 验证范围

此前 RC12 后端首次完整测试有两条旧预期失败；修正后定向复测四类共 17 项。汇总后的报告不等于重新执行了一次全量测试。前端此前全量 61 项通过，相关视图定向 24 项通过，类型检查与构建通过。打包接口验证覆盖发布、任务推进、重复运行与重启。

回填验收没有额外调用真实模型，浏览器自动化当时不可用，不能把接口验证说成浏览器自动化端到端通过。视频中的分析为独立的实际云端调用。

## 使用注意

- 接收方提供自己的模型 Key；不启用模型也可使用本地数据链与 Java 事实功能。
- 干净运行包不附带录像中的新增监测项与录制后数据。
- 单位必须与配置一致，材料示例为“元/吨”，不是 CNY。
- 默认业务日历为周一至周五，不是完整节假日／调休交易日历。
- 过长监测项编号可能触发 Windows 临时文件名限制，本版没有修改底层存储协议。
- RC12 为候选版；升级前关闭应用并备份 data，不覆盖唯一业务目录。
