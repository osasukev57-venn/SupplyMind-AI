# 题目：供应链成本监测与动态调价预警智能体

## 项目任务概述

### 项目目标

开发基于 Windows 平台的智能化成本监控与预警智能体。本项目要求构建能够自动聚合官方信息源、执行数据核验与本地文件留存、并将核心内容进行面板展示的系统。系统需支持使用者自主配置监测对象，确保从信息抓取、展示到决策全过程的数据权威性与业务闭环性。

### 项目需求

#### 信息来源与多级数据处理

核心信息来源：每日定时自动抓取官方权威数据。

汇率数据：来源于中国人民银行发布的官方汇率。

原材料价格：来源于上海有色金属网（SMM）、亚洲有色金属网（Asian Metal）指定的原材料。

数据计算逻辑：基于每日获取的底层价格数据，系统需对监控标的进行时间序列聚合计算。计算链路遵循：每日加工均值 > 月度均值 > 季度均值 > 半年度均值 > 年度均值。

数据核验：建立数据核验机制，通过多信源比对或校验规则确保获取数据的准确性，避免幻觉或过期信息影响系统输出。所有未经校验的数据不得进入展示层。

#### 本地化文件存储机制

数据可采用本地结构化文件（如 JSON、CSV 格式）进行持久化存储。数据库非必需项目但要考虑既往数据的调用问题.

存储内容：抓取的原始每日数据、计算后的多级均值数据及预警记录需写入文件留存。

文件轮转管理：系统需具备自动分卷管理机制（例如按月或按年自动生成新的存储文件），防止单文件体积过大。

历史信息跨卷读取：前端面板或智能体在进行跨周期分析时，系统需自动跨文件检索并拼接历史数据，保障数据读取的连贯性。

#### 面板信息流与动态配置

基础面板信息展示（默认配置）：

汇率监测：展示中国人民银行每天的汇率（欧元、美元），输出每日加工均值及月度、季度、半年度、年度均值。

原材料监测（SMM）：展示上海有色金属网每天的原材料价格均值（ADC12、AZ91D），输出月度、季度、半年度、年度均值。

原材料监测（Asian Metal）：展示亚洲有色金属网每天的原材料价格均值（ADC12、AZ91D），输出月度、季度、半年度、年度均值。

### 技术要求

平台支持：开发以 Windows 桌面端为主。

数据准度：系统数据需绝对准确，必须包含校验步骤以保证数据正确性。

### 交付要求

提供完整的工程源代码及本地化部署手册。

### 验收要求

#### 数据链条与精度验收：

随机抽取历史自然月，要求系统展示指定货币与原材料的“每日加工均值”，核验系统的“月度、季度、半年度、年度”均值计算结果准确无误，无计算精度流失。

#### 本地文件存储机制验收：

检查程序目录，确认数据以规定格式（如 JSON/CSV）存储，无隐藏的数据库运行进程。

更改系统时间触发跨期操作，验证系统已自动创建新的轮转文件。

在多份历史轮转文件存在的状态下，执行跨年度数据查询，验证系统能成功读取并拼接历史文件。

#### 组件动态联动与修改验收：

可以由用户修改监测标的（例如：停止监测欧元，新增英镑对人民币汇率监测；将原材料监测中的 AZ91D 更换为其他标的）。

验证面板实时重构，旧标的隐藏，新标的成功拉取其当日数据与历史均值数据，且系统无异常报错。
