# rc8 报告展示验收

本版仅改善 Agent 报告阅读体验，后端与事实校验未改变。不要覆盖旧目录，也不要为查看报告再次导入数据。

1. 关闭旧 SupplyMindAI 窗口。
2. 打开交接消息中的 rc8 验收目录，双击根目录的“启动-本地Agent验收.cmd”。它不启用云端。
3. 进入 Agent 工作台，在“读取已保存报告”粘贴 `report/2026-10/report-req-cc0732a4-266.json`，点击“核验并打开报告”，不要点“提交分析”。
4. 截取报告信息、全部采用状态，以及概览、趋势、两组均值、预警与确认、数据质量六张解读卡片。Java 摘要默认收起，展开后不应显示云端未采用的矛盾文案。
5. 核对 25500 元/吨、24800 / 23200 两组月均、r4 预警已确认和模拟数据说明。宽窗口双列，窄窗口单列。
6. 正常关闭并再次打开后，使用同一报告标识重新核验，检查数据和确认记录仍保留。

此步骤读取此前由 qwen-plus 实际生成的报告，不新增模型请求。录屏应明确是历史真实云报告，不是现场新调用；不把 Java 摘要或部分采用说成云端全部采用。
