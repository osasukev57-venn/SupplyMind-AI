# SupplyMind AI 批量导入演示数据

本目录用于演示 **LocalImport 本地文件导入 → PENDING → 批量校验 → 发布 → daily/aggregate 重建 → 面板查询** 的完整链路。数据为模拟验收数据，不代表真实市场行情，不应参与正式业务判断。

## 1. 先新增本地导入监测项

在“动态配置 → 新增监测项”填写：

- 监测项编号：`MAT.AZ91D.DEMO_IMPORT`
- 名称：`AZ91D模拟导入数据`
- 来源意图：`模拟验收数据`
- 接入方式：`本地导入`
- 数据类型：`material`
- 单位：`元/吨`
- 基础币种：`CNY`
- 历史回填起止日期：留空

提交成功后，配置应显示：

- Provider：本地导入
- AccessMethod：本地导入
- Route：直接本地导入
- fallbackReason：无

## 2. 一次导入六行数据

进入“来源与录入 → 文件导入”，选择：

`SupplyMindAI-AZ91D-local-import-demo.csv`

上传后六行只会进入 `RECEIVED + PENDING`，这是 raw-first 的受理边界。

## 3. 显式批量校验并发布

点击“批量校验并发布到面板”。系统逐行执行：

`校验 → 发布 → daily 重建 → 月/季/半年/年度 aggregate 重建`

每行会独立显示结果；一行失败不会阻断其他行。重复点击属于幂等重算，不会重复造数。

## 4. 查看结果

- “总览”：查看该监测项最新值 `24900` 和本月均值。
- “历史趋势”：选择 `MAT.AZ91D.DEMO_IMPORT`，查询 `2026-08-17` 至 `2026-08-24`。
- “数据质量”：核对六行的校验状态和来源。
- “Agent 工作台”：有可用正式发布数据后，可按监测项与日期查询；云模型不可用时会降级为 Java 本地可信报告。
